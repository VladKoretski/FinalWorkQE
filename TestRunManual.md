# Руководство запуска тестов  

## Клонировать репозиторий  
Для начала работы необходимо клонировать репозиторий. Для этого необходимо выполнить следующее:
1. Создаем рабочую директорию
2. В рабочей директории запускаем терминал git bash
3. В терминале git bash выполняем команду:
   git clone https://github.com/VladKoretski/FinalWorkQE

## Обеспечить необходимое окружение  
1. Установленная IDE Android Studio  
2. Настроенный эмулятор:  
* Android 14, API 34 (Pixel 5 API 34)  
3. ... или присоедино физическое устройство (мобильный телефон) с включенным режимом разработчика  
* Android 14, API 34 (Pixel 5 API 34)
4. Java (JDK11)

## Запустить тесты
Для запуска тестов необходимо выполнить следующее:
1. Открыть клонированный проект в Android Studio;
2. Установить приложение на эмулятор или физическое устройство;
3. Запустить тесты одним из способов
   * первый способ: через терминал IDE:
     1. Запустить тесты в терминале IDE, введя команду ./gradlew connectedAndroidTest
   * второй способ: через меню и package:
     1. Развернуть папку ...app/src/androidTest/java/ru/iteco/fmhandroid/ui/tests
     2. Кликнуть правой кнопкой по папке tests
     3. Выбрать и кликнуть Run test in 'package name'
    * третий способ: с помощью горячих клавиш
     1. Набрать Ctrl+Shift+F10
